# UA Shutdowns — графіки відключень світла ДТЕК

[English](README.md) · **Українська**

Графіки відключень світла за вашими адресами. Розширення для Google Chrome, що полегшує отримання, відображення та поширення графіків із сайтів ДТЕК.

## Що вміє розширення

- Зберігає кілька адрес і показує для кожної чергу та години відключень.
- Відкриває потрібний сайт ДТЕК і автоматично заповнює адресу.
- Зберігає отримані графіки: їх можна переглядати за датами, зокрема без інтернету.
- Дозволяє копіювати графік або передавати його на телефон через QR-код.
- За бажанням закриває спливаючі вікна на сайтах ДТЕК, що заважають перегляду.

## Як встановити

Потрібен **Google Chrome 127 або новіший**.

### Із Chrome Web Store — після публікації

Розширення ще не опубліковане в Chrome Web Store. Після публікації це буде рекомендований спосіб встановлення:

1. Відкрийте [Chrome Web Store](https://chromewebstore.google.com/) у Google Chrome та знайдіть **UA Shutdowns**.
2. Відкрийте сторінку розширення й натисніть **«Додати в Chrome»**.
3. Підтвердьте встановлення у вікні браузера.
4. Для зручного доступу закріпіть UA Shutdowns на панелі розширень Chrome.

Для цього способу не потрібно завантажувати архів або вмикати режим розробника. [Довідка Google про встановлення розширень](https://support.google.com/chrome_webstore/answer/2664769?hl=uk).

### З архіву — доступно зараз

До публікації в магазині розширення можна встановити вручну з GitHub. Після публікації цей спосіб залишиться альтернативою для ручного встановлення й тестування:

1. Завантажте ZIP із [останнього релізу](https://github.com/yuriyapostol/ua-shutdowns/releases/latest) та розпакуйте його в окрему папку.
2. Відкрийте `chrome://extensions` і ввімкніть **«Режим розробника»**.
3. Натисніть **«Завантажити розпаковане розширення»** та виберіть папку з файлом `manifest.json`.
4. Для зручного доступу закріпіть UA Shutdowns на панелі розширень Chrome.

## Як користуватися

### Додайте адресу й отримайте графік

1. Відкрийте розширення та натисніть **«Додати адресу»**.
2. Оберіть регіональне представництво ДТЕК, введіть адресу й збережіть її. Для Києва місто вже вибрано.
3. Натисніть збережену адресу. Розширення відкриє сайт ДТЕК і підставить її у форму.
4. Дочекайтеся появи графіка на сайті й відкрийте розширення, щоб переглянути отримані години відключень.

Так можна додати кілька адрес.

Вводьте адресу українською, як на сайті ДТЕК, незалежно від мови інтерфейсу. Інакше адресу не буде знайдено. Наприклад: місто — `Київ`, вулиця — `Хрещатик`, будинок — `22`.

### Змініть адресу

Натисніть олівець біля адреси, внесіть зміни й натисніть «Зберегти».

Зміни регістру, пробілів або додавання чи прибирання типу («вул.», «м.» тощо) зберігаються одразу зі збереженням черги та графіків. Наприклад, `17 А` → `17 а`.

Для інших змін розширення покаже «Було / Стало» й запропонує вибір:

- **«Уточнюю адресу»** — залишити її історію.
- **«Це інше місце»** — почати нову історію, зберігши попередні архіви черг.

Зміна типу («вул.» → «пров.», «м.» → «с.»), літери чи цифри будинку може означати інше місце. Після таких змін відкрийте адресу на сайті ДТЕК для повторної перевірки черги.

### Переглядайте графіки за датами

На головному екрані можна вибрати сьогодні, завтра або іншу дату стрілками чи в календарі. Для будинків із двома лініями графіки показуються окремо.

У налаштуваннях можна вибрати українську, англійську, німецьку, французьку, іспанську, італійську, польську або **«Як у браузері»** (типовий варіант). Автоматичний вибір використовує мову інтерфейсу Chrome, а для непідтримуваних мов — англійську. Зміни зберігаються й застосовуються одразу, зокрема до тексту поширення графіка. Формати дат і тижні в календарі відповідають локалі користувача з урахуванням її регіональних налаштувань: порядок складових дати й роздільники, назви місяців і днів тижня, перший день тижня. Наприклад, для української це `ДД.ММ.РРРР` і початок тижня з понеділка, для американської англійської — `MM/DD/YYYY` і з неділі, для британської — `DD/MM/YYYY` і з понеділка. Якщо мова Chrome збігається з вибраним перекладом, зберігаються її регіональні налаштування; інакше використовується типова локаль перекладу. Дати відключень завжди визначаються за київським часом.

Розширення отримує дані з відкритої активної вкладки ДТЕК. Щоб оновити графік для потрібної адреси, натисніть її та дочекайтеся завантаження даних на сайті. Без інтернету доступні лише раніше збережені графіки.

Якщо бачите **«Графік не отримано»** або **«Графік не збережено»**, даних за вибрану дату немає. Це не означає, що відключень не буде.

### Архіви та видалення

Отримані графіки зберігаються без автоматичного строку видалення. У **«Налаштування → Архіви черг»** можна переглядати дати й інтервали за населеними пунктами та чергами. Різні версії графіка одного дня показуються окремо.

Щоб видалити адресу, відкрийте її редагування й натисніть кошик. Вулиця й будинок видаляються, а архіви черг залишаються. Для нової або повторно доданої адреси однозначні збережені графіки відображаються після підтвердження її черги на сайті.

Сам архів можна видалити в налаштуваннях з окремим підтвердженням. Це також прибере його графіки з історії всіх пов’язаних адрес.

### Поділіться графіком

Натисніть **«Поділитись графіком»** біля адреси. На екрані поширення можна скопіювати текст або відсканувати QR-код камерою телефона.

Перед копіюванням текст можна відредагувати. QR-код також міститиме відредагований текст; збережений графік при цьому не зміниться.

### Приберіть спливаючі вікна

У **«Налаштуваннях»** увімкніть автоматичне закриття спливаючих вікон на сайтах ДТЕК. Розширення також може запропонувати це, коли виявить таке вікно.

## Конфіденційність і збережені дані

[Повна політика конфіденційності](PRIVACY.uk.md) · [Заповнення Privacy practices для Chrome Web Store](store/privacy-practices.uk.md)

Адреси, налаштування та історія графіків зберігаються лише локально у вашому браузері. Розширення не надсилає ці дані розробнику та не використовує аналітику чи відстеження.

Для отримання графіка вибрана адреса підставляється у форму на відповідному сайті ДТЕК і обробляється цим сайтом. Поширення графіка відбувається лише за вашою дією; QR-код створюється локально, без надсилання його вмісту зовнішнім сервісам.

Архіви черг не містять вулиць і будинків. Видалення розширення очищає всі його збережені дані; окремі резервні файли на диску залишаються.

## Для розробників

Для встановлення з вихідного коду виберіть папку репозиторію на кроці «Завантажити розпаковане розширення».

Для QR-кодів використовується [qrcode-generator v3.4.0](https://github.com/yuriyapostol/qrcode-generator/tree/v3.4.0), оголошений у `package.json`. Потрібні модулі зберігаються у `vendor/`, тому встановлення розширення не потребує npm або збірки.

Перевірки для розробки:

```sh
npm ci --ignore-scripts
npm run vendor:check
npm test
```

Для оновлення бібліотеки замініть `<version>` на номер її версії:

```sh
npm install --ignore-scripts --save-exact "qrcode-generator@github:yuriyapostol/qrcode-generator#v<version>"
npm run vendor:sync
npm run vendor:check
npm test
```

Додавайте до коміту зміни `package.json`, `package-lock.json` і `vendor/` разом. CI перевіряє відповідність локальних модулів зафіксованій залежності.

Для нового релізу оновіть версію в `manifest.json`, додайте відповідні розділи в обох мовних версіях історії змін та опублікуйте тег `v<версія>`. GitHub Actions запустить перевірки та створить Release із ZIP для встановлення й двомовним описом змін: спочатку українською, потім англійською.

Щоб додати мову інтерфейсу або Chrome Web Store, скористайтеся [інструкцією для перекладачів](TRANSLATING.uk.md). Словники містять контекст та іменовані підстановки; перевірки автоматично знаходять усі мови. Готові повні описи магазину зберігаються в `store/<мова>/description.txt`. Документація залишається двомовною.

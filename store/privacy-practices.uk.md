# Chrome Web Store — Privacy practices

[English](privacy-practices.md) · **Українська**

Підготовлено для маніфесту 0.7.1, 25 листопада 2026 року. Це інструкція для подання, а не заміна полів кабінету чи [політики конфіденційності](../PRIVACY.uk.md). Відповіді потрібно внести в Chrome Web Store Developer Dashboard → Privacy practices. Перед поданням звірте їх із фактичними формулюваннями форми.

## Єдине призначення

Отримання, перегляд, архівування й поширення графіків відключень ДТЕК для вибраних користувачем адрес у підтримуваних регіонах України.

Для англомовних полів копіюйте готові тексти з [англійської версії](privacy-practices.md).

## Обґрунтування дозволів

| Дозвіл | Призначення |
| --- | --- |
| storage | Локальне зберігання адрес, черг, історії графіків і налаштувань. Сховище сеансу пов’язує вкладку ДТЕК із вибраною адресою. |
| unlimitedStorage | Архів щоденних графіків та їхніх версій з налаштовуваною тривалістю зберігання (365 днів за замовчуванням); звичайна квота Chrome не повинна переривати зберігання. Архіви можна видаляти в налаштуваннях. |
| activeTab | Після відкриття розширення користувачем — перевірка URL активної вкладки, оновлення показаного графіка й повторне використання поточної вкладки ДТЕК для адреси. |
| Доступ до сайтів / content scripts, якщо поле показано | Робота лише на HTTPS-сторінках /ua/shutdowns доменів dtek-kem.com.ua, dtek-krem.com.ua, dtek-dnem.com.ua, dtek-oem.com.ua, dtek-dem.com.ua та їхніх піддоменів: заповнення адреси, читання черг і графіків, необов’язкове закриття спливаючих вікон. |

## Віддалений код

Оберіть **No, I am not using remote code**. Виконуваний код і генератор QR входять у ZIP. Читання графіка зі сторінки ДТЕК не є завантаженням виконуваного коду розширення.

## Використання даних

«Розробник не отримує дані» не означає «розширення не обробляє даних». Адреси зберігаються локально й підставляються у форми ДТЕК; графіки читаються з цих сайтів. FAQ Google вимагає розкривати й локальну обробку.

Категорії, які слід звірити з точними визначеннями актуальної форми:

| Категорія | Підстава |
| --- | --- |
| Personally identifiable information | Введені адреси з вулицею й будинком. Імена, email та облікові дані не запитуються. |
| Location | Вибрана поштова адреса: регіон, населений пункт, вулиця, будинок. GPS, геолокація за IP і поточне місцеперебування пристрою не запитуються. |
| Website content | Черги, дати й інтервали графіків зі сторінок ДТЕК. |

Не позначайте медичні, фінансові/платіжні, автентифікаційні дані чи особисте листування: розширення їх не збирає. Кліки, рухи миші й натискання клавіш не записуються для аналітики. URL активної вкладки перевіряється для роботи функцій, але історія перегляду не архівується й не передається; якщо визначення у формі охоплює таку необхідну обробку URL, розкрийте її в Web history. Це інструкція для звіряння, а не вже заповнена декларація.

Поточна реалізація відповідає трьом запевненням Limited Use: відсутність продажу чи передавання поза дозволеним використанням, стороннього використання та використання для кредитоспроможності чи кредитування. Позначайте їх після прочитання тексту запевнень у кабінеті.

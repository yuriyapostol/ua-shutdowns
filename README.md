# UA Shutdowns
Розширення Chrome для автоматичного вибору адреси на сторінці відключень ДТЕК.

Для встановлення завантажте файли репозиторію в окрему папку. Відкрийте
`chrome://extensions`, увімкніть режим розробника, натисніть «Завантажити
розпаковане розширення» та виберіть папку з `manifest.json`.

Натисніть іконку розширення, введіть місто / населений пункт, вулицю та
номер будинку й натисніть «Зберегти налаштування». Налаштування зберігаються
локально в розширенні та відновлюються при наступному відкритті віконця.
Після збереження перезавантажте сторінку графіка ДТЕК, щоб застосувати адресу.
До першого збереження поля адреси порожні й автовибір не запускається.

Галка «Автоматично закривати спливаючі вікна» вмикає закриття модальних
вікон ДТЕК через штатні елементи закриття. За замовчуванням вона вимкнена.
Галка зберігається одразу при перемиканні, незалежно від редагування адреси,
і застосовується також до вже відкритих сторінок графіка. Закриваються й
вікна, що з’являються із затримкою. Якщо обробник закриття ще не готовий,
розширення повторює спробу через 300 мс, доки опція увімкнена.

Після оновлення файлів розширення натисніть «Оновити» на `chrome://extensions`
і перезавантажте сторінку ДТЕК, щоб завантажити нові скрипти.

Розширення послідовно обирає місто, вулицю й будинок із підказок сайту ДТЕК.
Вводить назву цілими словами: спочатку перше слово, а якщо потрібного
пункту ще немає в підказках, додає наступне («Героїв» → «Героїв Небесної»
→ «Героїв Небесної Сотні»). Щойно з’являється точний збіг після нормалізації,
натискає його; якщо всі слова вичерпано, обирає найближчий достатньо схожий
варіант серед знайдених. Повні назви та їхній регістр встановлює сам сайт після кліку;
розширення не вводить назви вибраних пунктів повторно.
Порівняння враховує регістр, пробіли, скорочення типів географічних об’єктів
і близькі написання. Позначення типу «м.» або «вул.» пропускаються в запитах;
слова не скорочуються до фрагментів.
Будинки з іншим основним номером не підставляються.

Автовибір запускається один раз після завантаження сторінки. Взаємодія з
полями адреси або списками одразу скасовує його. Якщо немає достатньо
близького збігу або поле не готове протягом 10 секунд, пошук зупиняється;
локацію можна вибрати вручну.

Перевірки без додаткових залежностей:

```sh
node tests/address-selection.test.cjs
node tests/address-settings.test.cjs
node tests/popup-closer.test.cjs
```

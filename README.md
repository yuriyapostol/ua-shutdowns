# UA Shutdowns

Розширення Chrome для автоматизації перевірки відключень електроенергії на регіональних сайтах ДТЕК.

Розширення запам’ятовує адресу, обирає її на сторінці відключень і за бажанням
закриває спливаючі вікна, що перекривають графік. Адресу завжди можна змінити вручну.

## Можливості

- Збереження міста, вулиці та будинку у вікні розширення.
- Автоматичний вибір найближчих відповідників адреси з підказок сайту.
- Пошук цілими словами з урахуванням скорочень, регістру й пробілів.
- Скасування автовибору, щойно користувач починає змінювати адресу.
- Автоматичне закриття спливаючих вікон за окремою галкою.

Адреса й налаштування зберігаються локально у браузері. До збереження адреси
автовибір не запускається.

## Підтримувані сайти

| Регіон | Сторінка відключень |

| Київська область | [dtek-krem.com.ua](https://www.dtek-krem.com.ua/ua/shutdowns) |
| Дніпропетровська область | [dtek-dnem.com.ua](https://www.dtek-dnem.com.ua/ua/shutdowns) |
| Одеська область | [dtek-oem.com.ua](https://www.dtek-oem.com.ua/ua/shutdowns) |

Для Києва вкажіть у налаштуваннях місто «Київ»: на цьому сайті обираються лише
вулиця й будинок. Адреса іншого населеного пункту там автоматично не підставляється.

## Встановлення

1. Завантажте ZIP із [останнього релізу](https://github.com/yuriyapostol/ua-shutdowns/releases/latest) та розпакуйте його в окрему папку.
2. Відкрийте `chrome://extensions` і ввімкніть режим розробника.
3. Натисніть «Завантажити розпаковане розширення» та виберіть папку з `manifest.json`.

Для встановлення з вихідного коду так само можна використати папку репозиторію.

## Користування

1. Натисніть іконку UA Shutdowns, введіть адресу й натисніть «Зберегти налаштування».
2. За потреби ввімкніть «Автоматично закривати спливаючі вікна». Ця галка зберігається одразу.
3. Відкрийте відповідний сайт ДТЕК із таблиці вище або перезавантажте вже відкриту сторінку.

Після зміни адреси перезавантажте сторінку графіка. Після оновлення файлів
розширення також натисніть «Оновити» на `chrome://extensions`.

## Розробка

Перевірки без додаткових залежностей:

```sh
node tests/address-selection.test.cjs
node tests/address-settings.test.cjs
node tests/popup-closer.test.cjs
```

Для нового релізу оновіть версію в `manifest.json`, додайте відповідний розділ
у `CHANGELOG.md` та опублікуйте тег `v<версія>`. GitHub Actions запустить
перевірки, створить Release з описом змін і додасть ZIP для встановлення.
